# An-Nuur Digital
Web app HTML/CSS/JS untuk GitHub Pages: galeri video YouTube + jam digital dan jadwal sholat.

## Deploy
1. Buat repository GitHub.
2. Upload `index.html`, `style.css`, dan `script.js`.
3. Settings → Pages → Deploy from a branch → `main` / root.
4. Simpan dan tunggu GitHub Pages aktif.

## Catatan
Jadwal sholat pada versi ini adalah data contoh. Untuk jadwal yang akurat per daerah, bagian `prayerTimes` di `script.js` perlu dihubungkan ke API jadwal sholat atau diisi sesuai jadwal resmi setempat.
